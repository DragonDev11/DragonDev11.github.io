Stockify

Stockify was originally my final-year project (PFE) at the Higher School of Technology of Meknes (ESTM). It's a stock management web application featuring:

  • Product, invoice, user, quotation & category management
  • AI-powered invoice scanning
  • User hierarchy roles (Super Admin, Admin, User)
  • Order state control system

Status: Released

Tech stack: PHP, MySQL, JavaScript, AI integration using NodeJS.
